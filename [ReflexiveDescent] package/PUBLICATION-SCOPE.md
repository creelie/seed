# Publication scope — v1.3.0

Author: Deep Bhattacharjee. The earlier joint manuscript with Ushashi
Bhattacharya is credited in a footnote and the original references.

The geometric free-sum order isomorphism and depth-additivity core have
checked Lean proofs. The stored 5592-node graph has both root shortest
lengths 22, with kernel reduction, axiom audits and negative controls.
This does not formalize all geometric cover completeness or the KS census.
The exact D4 remains unknown; the manuscript gives 22 <= D4 <= 346 relative
to the supplied census and retains 348 as the arbitrary-descent bound.
The whole manuscript is not formalized, peer-reviewed or journal-accepted
by this release. No Hexagon or journal submission is performed.
